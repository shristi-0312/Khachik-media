# Khachik Media

Portfolio site for Khachik Media. The app lives in [`khachik-media-site/`](khachik-media-site/).

## Develop

```bash
cd khachik-media-site
npm install
npm run dev
```

## Deploy

Vercel root directory: `khachik-media-site` (SPA rewrites are in `khachik-media-site/vercel.json`).

## Routes

- `/` — Home (with projects globe)
- `/projects`, `/projects/:slug`, `/about`
- Dark showcase: `/dark`, `/dark/projects`, `/dark/about`, …
